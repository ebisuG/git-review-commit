# git-review-commit
## Overview
As a non-native English speaker, I'm always not sure how my commit message is suitable. Pasting a draft commit message to a chat with AI is a little painful, because during my development I'm on Git CLI, I should change it to browser. Complete "Git Commit Message Review" is the purpose of this tool. I know these days the opportunity of writing code manually is decreasing, however I think that is a good practice to use AI tool under controll and amplify my ability, so this is why I developed this tool.
